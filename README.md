## 📌 Project Description

This project is a **C# Console Cybersecurity Awareness Chatbot** designed to educate users about common online threats and safe internet practices.

The chatbot interacts with users, provides cybersecurity tips, and helps raise awareness about topics such as phishing, malware, password security, and safe browsing.

* 🎤 Voice greeting using a `.wav` audio file
* 💬 Interactive chatbot with menu system
* 👤 User name personalization
* 🎨 Styled console interface with colors and ASCII art
* ⌨️ Typing animation effect for responses
* 🔐 Cybersecurity awareness information
* 🧱 Structured using multiple classes (OOP)

# SecureNet - Cybersecurity Chatbot
A WPF-based cybersecurity awareness chatbot built in C# for PROG6221 Part 2.

## Student Details
- Name: Musa Boltina
- Student Number: ST10471931

## Features
- Modern WPF dark-themed GUI
- Voice greeting on startup
- ASCII art header
- 10 cybersecurity keyword topics with random responses
- Sentiment detection (worried, curious, frustrated, happy)
- Empathetic responses based on user mood
- Memory and recall of user name and favourite topic
- Follow-up conversation flow using "tell me more"
- Topic menu buttons on the left panel
- Fallback responses for unrecognised input

## How to Run
1. Clone this repository
2. Open the .slnx file in Visual Studio 2022
3. Set CybersecurityChatbotGUI as the startup project
4. Make sure greeting.wav is set to Copy Always in properties
5. Press F5 to run

## Prerequisites
- Visual Studio 2022
- .NET 8.0
- Windows OS

## Voice Greeting
The greeting.wav file is located inside the CybersecurityChatbotGUI project folder.
It must be set to Copy to Output Directory = Copy Always in Visual Studio properties.
